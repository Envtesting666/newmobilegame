# Football Manager AI - Dynamic LLM-Powered Simulation

A narrative football management simulation powered by Google Gemini AI, combining the storytelling depth of "As Dusk Falls" with the strategic gameplay of "Football Manager" and the accessibility of "FIFA Career Mode".

## 🎯 Core Features

- **100% Dynamic Content**: Every dialogue, tweet, and match event is contextually generated by AI
- **Live Commentary**: AI-powered voice commentary in Turkish and English
- **Social Media Simulation**: Real-time Twitter/X feed with AI-generated reactions
- **Intelligent Match Engine**: Multi-factor simulation considering team quality, tactics, morale, and more
- **Dynamic Transfers**: Fully LLM-driven negotiations with clubs and players
- **Real-World Data**: Current 2024-25 season data for La Liga and Turkish Süper Lig

## 🚀 Technology Stack

- **Frontend**: React 18 + TypeScript
- **AI Engine**: Google Gemini (Intelligence, Speech, Chatbot, Image Generation)
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Database**: Firebase Firestore
- **Platform**: Gemini Apps Builder

## 📋 AI Features Integration

1. **Nano Banana** - Visual content generation (match graphics, player cards, transfer announcements)
2. **Gemini Intelligence** - Core game logic, match simulation, strategic AI
3. **AI Chatbot** - Press conferences, transfer negotiations, player conversations
4. **Generate Speech** - Live match commentary and voiceovers
5. **Fast AI Responses** - Real-time updates and notifications

## 🔧 Setup Instructions

1. Clone the repository
2. Install dependencies: `npm install`
3. Configure Gemini API keys in `.env`
4. Run development server: `npm start`
5. Build for production: `npm build`

## 🎨 Design Philosophy

- **Apple-Inspired UI**: Minimalist, elegant design with 60 FPS animations
- **Mobile-First**: Optimized for mobile gaming experience
- **Dark Mode**: Default dark theme with light mode option
- **Zero Placeholder Content**: Everything is AI-generated and contextual

## 📱 Game Flow

1. **Initialization**: Enter your name → Select league → Choose team
2. **Career Mode**: Manage tactics, transfers, training, and morale
3. **Match Days**: Watch live simulations with AI commentary
4. **Social Media**: Experience Twitter reactions to every event
5. **Progress**: Win trophies, develop players, build a dynasty

## 🎯 Development Phases
