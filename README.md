# Akkaya Games - Destiny-Inspired Game Menu

A professional, futuristic game menu interface inspired by Destiny's UI design, built with React and TypeScript.

## Features

- **Modern Design**: Sharp lines, layered transparency, and a cold color palette with a powerful accent color
- **Three Main Views**: Main Menu, Settings Menu, and Career Mode
- **Multi-language Support**: Full i18n support for Turkish and English
- **Audio System**: Background music and click sound effects
- **Settings Management**:
  - Language selection (TR/EN)
  - Resolution options
  - Fullscreen toggle
  - Volume control with mute functionality
- **Career Mode**:
  - League selection (Süper Lig / La Liga)
  - Team selection with interactive cards
  - Visual feedback with Destiny-inspired active state effects
- **Responsive Design**: Works seamlessly on mobile and desktop devices
- **Smooth Animations**: Fade-in effects and smooth transitions

## Technologies

- React 18
- TypeScript
- Inline CSS (CSSProperties)
- No external UI libraries

## Installation

```bash
npm install
```

## Running the Application

```bash
npm start
```

The application will open in your browser at `http://localhost:3000`.

## Building for Production

```bash
npm run build
```

## Design Philosophy

The interface follows Destiny's design principles:
- Dark background (#0a0e14, #141922, #0f1419)
- Accent color: Bright blue (#4a90e2)
- Sharp geometric shapes
- Transparent layers with subtle borders
- Inset shadows for active states
- Minimal, clean typography
- No glowing or neon effects
